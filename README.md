# Digital Image Compression System (2D-DCT)

A single-file HTML web app that demonstrates image compression with the two-dimensional Discrete Cosine Transform (2D-DCT), the technique behind JPEG.

## Features

- Load an image from the gallery or your device (PNG, JPG, BMP), or a PDF document
- Live camera feed compression
- Standard generated test patterns
- Adjustable Quality Factor (Q), from max quality to high compression
- Side-by-side view: original image (spatial domain) vs reconstructed image (IDCT result)
- Quality and compression metrics: Mean Squared Error (MSE), Peak Signal-to-Noise Ratio (PSNR), Compression Ratio (CR), estimated compressed size and storage savings

## Usage

Open `index.html` in any browser, or visit the live demo. No installation or server needed.

Live demo: https://mm9036922-gif.github.io/dct-image-compression/
